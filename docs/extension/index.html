Why Use the Extension?

Instead of opening developer tools and typing console commands, the tag-to-json Inspector extension lives right in your browser toolbar:

1. Toolbar Popup
Click Extension Icon

Scans all elements with an ID on the current active tab automatically.

2. ID Selector
Select & Filter

Filter and pick the exact table, header, or card component you want to capture.

3. Instant Save
1-Click Download

Downloads the generated <id>-spec.json file ready for json-to-tag.

How to Install

Google Chrome / Brave / Edge
  1. Download and extract tag-to-json-extension-v2.0.0.zip.
  2. Open Chrome and navigate to chrome://extensions.
  3. Enable Developer mode (top-right toggle).
  4. Click Load unpacked and select the extracted folder.
Mozilla Firefox
  1. Open Firefox and navigate to about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on....
  3. Select the downloaded tag-to-json-extension-v2.0.0.zip file directly.
