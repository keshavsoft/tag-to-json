The Round-Trip Story

Full Cycle

Together, tag-to-json and json-to-tag create a complete lossless round-trip loop between native HTML browser elements and declarative JSON specifications:

1. Live DOM
Live Element

Any rendered HTML node, table, header, or card component

2. tag-to-json
Extract Spec

Traverses tag, attributes, classes, and nested children

3. JSON Tree
Declarative Spec

Portable, serializable JSON specification tree

4. json-to-tag
Rebuild DOM

buildSpecElement({ inSpec }) reconstructs identical DOM

Quick Integration

1. Install from npm
npm install @keshavsoft/tag-to-json
2. Import in JavaScript
import { tagToJson } from "@keshavsoft/tag-to-json";

// Pass an element or element ID:
const spec = tagToJson({
  inElement: document.getElementById("myTable")
});

console.log(spec);
Browser DevTools Console / Extension
// Load via script tag or WebExtension:
<script type="module" src="./dist/min.js"></script>

// Run directly in DevTools Console:
tagToJson({ inElement: $0 })

// Or extract by ID:
const spec = window.tagToJson("stockItemsTable");

// Copy straight to clipboard:
copy(JSON.stringify(spec, null, 2));
