Why Zero Dependencies Matters

In an ecosystem plagued by bloated node_modules trees and frequent security advisories, zero dependencies is an engineering choice that delivers massive practical advantages:

1. Total Supply-Chain Immunity

Modern software attacks heavily target npm dependencies via compromised accounts, typosquatting, or malicious post-install hooks. With zero runtime dependencies, tag-to-json presents a zero attack surface from third-party code.

2. Ultra-Lightweight Footprint (< 4 KB)

Traditional DOM parser libraries like Cheerio or JSDOM weigh between 7 MB and 18 MB unpacked, pulling in hundreds of transitive dependencies. tag-to-json weighs under 4 KB, making it ideal for instant script injection and resource-constrained environments.

3. Chrome & Firefox Manifest V3 Compliance

Browser extension stores (Google Chrome Web Store and Mozilla AMO) enforce strict Content Security Policies (CSP) forbidding dynamic eval(), WASM blobs, or remotely loaded code. tag-to-json passes browser store automated audits instantly.

4. Direct C++ Native Acceleration

Because tag-to-json operates directly on browser engine DOM primitives (W3C DOM Level 4), operations execute in compiled C++ inside Blink, Gecko, and WebKit without passing through multiple JavaScript abstraction layers.

5. Evergreen Stability & Long-Term Backward Compatibility

Web standards such as W3C DOM Level 4 are permanently maintained with backward compatibility by WHATWG and browser vendors. Unlike third-party libraries that release breaking major updates or become unmaintained, code built with native DOM standards will continue working reliably for decades.
