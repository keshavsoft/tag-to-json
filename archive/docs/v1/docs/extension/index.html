Why Use the Extension?

Instead of opening developer tools and typing console commands, the tag-to-json Inspector extension lives right in your browser toolbar:

1. Toolbar Popup
Click Extension Icon

2. ID Selector
Select & Filter

3. Instant Save
1-Click Download

Downloads the generated <id>-spec.json file ready for json-to-tag.

Extension W3C Extraction Pipeline (v5.0)

How the browser extension interacts with web pages to capture complete specs with zero text loss.

Mixed Content Safe

Browser extensions execute in an isolated world separate from the webpage's JavaScript context. The v5 extension packages a dedicated, self-contained W3C Tree Walker inside the content script: 

flowchart TD
    User(["User Clicks Toolbar Icon"]) --> Popup["Extension Popup (popup.html)"]
    Popup --> Scan["Scan Page for Elements with IDs / Full Page"]
    Popup --> Select["User Selects Target & Clicks 'Download Spec'"]
    
    Select --> Msg["chrome.tabs.sendMessage({ action: 'extractTagToJson' })"]
    Msg --> Content["Content Script (injectStart.js)"]
    
    Content --> Engine{"Is W3C Tree Walker Available?"}
    Engine -- Yes --> Walker["Run W3C Tree Walker over childNodes"]
    
    Walker --> E1["Node.ELEMENT_NODE (1): Recursive Spec"]
    Walker --> E2["Node.TEXT_NODE (3): In-Order Text"]
    Walker --> E3["Node.COMMENT_NODE (8): Ignore"]
    
    E1 --> Array["Preserve Vector Icons + Sibling Text Labels"]
    E2 --> Array
    
    Array --> JSON(["Generated <id>-spec.json"])
    JSON --> DL["1-Click Browser Download to Disk"]

Isolated World Independence

The extension does not depend on the host page loading any library or module. It ships with its own W3C DOM Level 4 tree extraction engine.

Full Round-Trip Fidelity

Captures elements containing both SVG graphics and label strings (like Bootstrap navigation items) without dropping button text or menu labels.

How to Install

Google Chrome / Brave / Edge
  1. Download and extract tag-to-json-extension-v5.0.0.zip.
  2. Open Chrome and navigate to chrome://extensions.
  3. Enable Developer mode (top-right toggle).
  4. Click Load unpacked and select the extracted folder.
Mozilla Firefox
  1. Open Firefox and navigate to about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on....
  3. Select the downloaded tag-to-json-extension-v5.0.0.zip file directly.
